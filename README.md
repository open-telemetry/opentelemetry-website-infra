# OpenTelemetry Website Infrastructure

This is the source repository for the observability infrastructure of the OpenTelemetry project's websites, [opentelemetry.io][] and [explorer.opentelemetry.io][].

The goal is to use OpenTelemetry to help maintainers understand how these websites behave and provide an example that others can learn from and adapt.

Site telemetry is intended to be publicly accessible, with sensitive information removed to protect visitors' privacy.

## Get involved

The project is in its early stages, with implementation planned in phases. If you are interested in contributing, start with the [project terminology](CONTEXT.md).

## Community

This project is run under the umbrella of the OpenTelemetry Communications SIG. The Communications SIG meets every two weeks on Tuesday at 9:00 AM PT. Check out the [OpenTelemetry community calendar][] for the Zoom link and any updates to this schedule.

Meeting notes are available as a public [Google doc][].

You can also reach out in the [#otel-comms][] channel on Slack.

If you are new to the CNCF Slack community, you can [create an account][slack].
